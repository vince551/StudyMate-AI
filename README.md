# StudyMate AI

> An AI-powered study companion designed for students who want a smarter, more structured way to learn.

## Vision

StudyMate AI combines AI tutoring, revision planning, note processing, quizzes, flashcards, and focused study tools in one student-first platform.

## Core Features

- 🤖 AI study tutor
- 📝 Note summarization and explanation
- 🧠 Quiz and flashcard generation
- 📅 Personalized revision planner
- ⏱️ Pomodoro focus sessions
- 📊 Study progress and performance tracking
- 📚 Subject and topic organization
- 📱 Responsive, installable PWA experience

## Product Principles

1. **Student-first UX** — fast, clear, distraction-free interfaces.
2. **Useful AI** — AI should explain, coach, and test understanding rather than simply provide answers.
3. **Privacy by design** — minimize unnecessary collection of student data.
4. **Accessible learning** — optimize for phones, low-bandwidth environments, and practical student workflows.

## Planned Stack

- Next.js + TypeScript
- Tailwind CSS
- Supabase / PostgreSQL
- Vercel
- AI SDK / LLM provider integration
